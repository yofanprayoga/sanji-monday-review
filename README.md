## The line

> My Monday gets one star. The alarm betrayed me, the Wi-Fi left me, and my to-do list reproduced overnight.

## How it works

`main.py` writes the line to `/output/entry.txt` (program/v1).

Run it:

```sh
python3 main.py
```
